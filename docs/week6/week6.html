Week 6: Kubernetes Fundamentals

Kubernetes is the de facto standard for container orchestration. This week focuses on understanding the fundamentals of Kubernetes and how to use it to deploy and manage containers.

Step 0: Start Fresh -- Clone the Repository

Start by cloning the Week 6 repository.

# Remove previous files
rm -rf ~/Docker-Workshop && \
 docker stop $(docker ps -aq) || true && \
 docker system prune -af && \
 docker volume prune -af && \
 docker system df -v

 # Switch to root user:
 sudo su -
